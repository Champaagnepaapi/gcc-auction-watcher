## Subject
Marketplace Insights item-level sold data — eligibility and production access path

## Body
Hello,

I am an eBay developer building a low-volume Pokémon single-card valuation/research tool. The application does not place bids, purchases, checkouts, payments, or automated orders.

I need item-level completed/sold listing data for exact-card valuation, specifically the eBay item ID, final sold price, currency, and sale/end date.

I also see that the Buy API production-access documentation describes an eBay Partner Network application and business-review process for production access.

3. Are there minimum business, traffic, revenue, partnership, or affiliate requirements for a small valuation/research application?

5. If Marketplace Insights cannot be granted, is there any other officially supported eBay API, feed, partner program, or commercial data product that provides item-level completed/sold listing IDs, final sold prices, and end dates?
6. If access is granted, are developers permitted to retain item IDs, sold prices, currencies, and end dates in a private historical valuation database, subject to eBay's API License Agreement and data-retention requirements?

The intended use is private market valuation and historical analysis of individual Pokémon cards. No automated commerce action is performed.

Thank you.
